# VibeRaven Production Skills Installed

Use the pack before an AI-built app is described as production-ready, launch-ready, or safe to deploy.

Start with:

```text
/viberaven-help
```

Run a production check:

```text
/viberaven-check
```

Use the launch gate:

```text
/viberaven-launch
```

The pack does not ask for secrets. When provider dashboard state is unknown, it asks for a redacted receipt, exported config, connected provider evidence, or a human check.
