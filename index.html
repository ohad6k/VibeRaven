Open-source local Studio for AI-built apps

Your AI agent builds it. VibeRaven controls it.

Run the Studio inside your repo to connect Codex, Claude, or Gemini, drag provider and release context into chat, and check whether the app is ready before users see it.

Run with npx Read the agent guide
npx -y viberaven
Agentic chat Connect local CLI agents and control access modes from the Studio.
Provider context Keep Supabase, Vercel, and Stripe proof visible and separate from repo fixes.
Release diffs Compare versions, explain changes, and find what shifted since a working release.
Local evidence No login, no telemetry, no scan quota. Markdown and JSON stay in your repo.

Community contributors

VibeRaven is public, inspectable, and built around agent-readable files. Star the repo, open issues, and help improve the production loop for AI-built apps.
