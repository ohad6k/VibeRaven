# Security

Please do not open a public issue for suspected vulnerabilities involving secrets, auth bypasses, provider credentials, or customer data.

Report security issues privately through GitHub Security Advisories when available, or contact the maintainer through the published project channels on [viberaven.dev](https://viberaven.dev).

## Safe Disclosure Details

Include:

- affected command or artifact
- minimal reproduction steps
- sanitized sample output
- expected impact

Do not include live tokens, cookies, service-role keys, raw `.env` values, or customer data in reports.

## Project Safety Rules

VibeRaven output should never expose:

- secrets, tokens, cookies, or raw env values
- Supabase service-role keys
- private provider credentials
- absolute local paths in public/chat output
- customer data from scanned projects
