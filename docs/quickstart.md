# Quickstart

Run VibeRaven from the root of an AI-built app:

```bash
npx -y @viberaven/cli --agent-mode
```

If login is required, the CLI opens a VibeRaven approval page. Complete login in the browser and keep the terminal running.

After the scan, inspect:

```text
.viberaven/agent-tasklist.md
.viberaven/report.html
```

Then follow `VIBERAVEN_NEXT_ACTION`.
